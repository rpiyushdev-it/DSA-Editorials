# DSA Editorials

A collection of problems explored, approaches I've developed, and all the small but vital lessons learned while studying data structures and algorithms during my undergrad.

This repository documents my problem-solving journey, with an emphasis on understanding the logic behind solutions rather than simply reaching an accepted answer.

## What You'll Find Here

Each editorial is documented as:

- *Problem Reference:* Link to the original problem.
- *Post Reference:* Link to the original post.
- *Intuition:* The thought process behind approaching the problem.
- *Approach:* A step-by-step explanation of the solution.
- *Implementation:* The code.
- *Complexity Analysis:* Time and auxiliary space complexity.
- *Learnings:* Possible improvements & alternative approaches, learned along the way.
